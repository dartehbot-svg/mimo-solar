# Солярная карта — полное описание программы

**Версия:** v1.1.0  
**Дата:** 17 августа 2026 г.  
**Платформа:** Mac mini (сервер) + MAX Messenger (бот)

---

## 1. Обзор

«Солярная карта» — астрологическая программа для расчёта натальных и солярных карт, интегрированная с мессенджером MAX. Пользователь общается с ботом в чате, вводит данные рождения и получает расчёты, описания и визуализацию.

### Что программа умеет
- **Натальная карта** — расчёт позиций планет, домов, аспектов на момент рождения
- **Солярная карта** — прогноз на год (момент возвращения Солнца в натальный градус)
- **Лучшее место** — поиск оптимального города для встречи дня рождения
- **Колесо карты** — PNG/SVG визуализация натальной или солярной карты
- **Описания** — краткое (150-300 слов) и полное (все планеты + аспекты) текстовые описания
- **Скачивание PDF** — полное описание в формате PDF
- **Профили** — хранение данных нескольких людей (семья, друзья)
- **История** — лог всех расчётов

### Технологический стек

| Компонент | Технология | Назначение |
|-----------|-----------|------------|
| Расчётное ядро | Python 3.11+, pyswisseph, FastAPI | Астрологические расчёты, REST API |
| Бот | Node.js 20+, TypeScript, @maxhub/max-bot-api | Общение с пользователем в MAX |
| БД | SQLite (aiosqlite) | Хранение пользователей, профилей, расчётов |
| Визуализация | Pillow (PNG), xml.etree (SVG) | Отрисовка колеса карты |
| PDF | ReportLab | Генерация PDF-отчётов |
| Процессы | PM2 | Управление процессами на Mac mini |
| Деплой | GitHub Actions + update.sh | Автообновления через GitHub Releases |

Каждый модуль заменяем независимо:
- Новые расчёты (транзиты, синастрия) — новый модуль + тип в `charts.type`

- Новые языки — структура `templates/ru/`, `templates/en/`

## 4. Расчёты

### 4.1 Натальная карта (`core/src/natal.py`)

**Вход:** дата, время, координаты, система домов (по умолчанию Placidus)

**Алгоритм:**
1. Парсинг даты/времени → `datetime`
2. Определение часового пояса по координатам (`timezonefinder`)
3. Конвертация в юлианскую дату (UT1) через `swe.julday()`
4. Расчёт позиций 12 планет через `swe.calc_ut()`:
   - Солнце, Луна, Меркурий, Венера, Марс
   - Юпитер, Сатурн, Уран, Нептун, Плутон
   - Истинный узел, Хирон
   - Опционально: Лилит, Церера, Паллада, Юнона, Веста
5. Расчёт 12 куспидов домов через `swe.houses()`
6. Привязка планет к домам (сравнение долготы с куспидами)
7. Расчёт аспектов (5 типов с орбами)

**Выход:** `NatalChart` — позиции планет, дома, ASC, MC, аспекты

**Система домов:** P=Placidus, K=Koch, E=Equal, O=Porphyry, W=Whole Sign

### 4.2 Солярная карта (`core/src/solar.py`)

**Вход:** натальная карта, год, координаты места встречи

**Алгоритм поиска момента соляра (3 шага):**
1. **Грубый поиск** (шаг 1 день): сканирование с 1 января, пока |sun_lon - natal_sun_lon| < 1°
2. **Уточнение** (шаг 1 час): поиск ±48 часов вокруг грубого результата
3. **Бинарный поиск** (бисекция): до точности < 0.001" (секунды дуги), 100 итераций

**Релокация:** дома, ASC, MC пересчитываются на координаты места встречи дня рождения.

**Наложение на натал:** определяется, в какие натальные дома попадают планеты соляра.

**Выход:** `SolarChart` — позиции планет, дома, момент соляра (UTC), наложение

### 4.3 Аспекты (`core/src/ephemeris.py`)

| Аспект | Угол | Орб | Цвет |
|--------|------|-----|------|
| Соединение | 0° | 8° | Золотой |
| Секстиль | 60° | 6° | Зелёный |
| Квадратура | 90° | 7° | Красный |
| Тригон | 120° | 7° | Синий |
| Оппозиция | 180° | 8° | Красный |

**Веса планет для орбов:** личные планеты (Солнце, Луна) — орб × 1.0, социальные (Юпитер, Сатурн) — × 0.8, трансформационные (Уран, Нептун, Плутон) — × 0.7.

### 4.4 Лучшее место (`core/src/best_place.py` + `core/src/scoring.py`)

**Алгоритм:**
1. Загрузка базы 168 городов из `cities.json`
2. Фильтрация (по стране, визовому режиму, часовому поясу)
3. Для каждого города: расчёт соляра → скоринг
4. Скоринг: для каждой целевой сферы → проверка домов → подсчёт весов планет
5. Сортировка по убыванию балла, топ-N

**Сферы → Дома:**
| Сфера | Дома |
|-------|------|
| Карьера | 10 |
| Любовь | 5, 7 |
| Здоровье | 1, 6 |
| Финансы | 2, 8 |
| Семья | 4 |
| Творчество | 5 |
| Духовность | 9, 12 |
| Общение | 3 |
| Дружба | 11 |

**Веса планет:** Солнце +3, Венера +3, Юпитер +3, Луна +2, Марс -2, Сатурн -2, Нептун -1.

## 5. Описания (Text Composer)

### 5.1 Структура базы текстов (`core/data/interpretations.json`)

```json
{
  "planet_in_house": {        // 10 планет × 12 домов = 120 записей
    "sun": {
      "1": { "short": "...", "full": "..." },
      "2": { "short": "...", "full": "..." }
    }
  },
  "house_in_sign": {          // 12 домов × 12 знаков = 144 записи
    "1": {
      "овен": { "short": "...", "full": "..." }
    }
  },
  "aspects": {                // 5 типов аспектов
    "conjunction": { "name": "...", "short": "...", "full": "..." }
  },
  "planets_in_signs": {       // Солнце и Луна в 12 знаках = 24 записи
    "sun": { "Овен": "...", "Телец": "..." }
  },
  "connectors": {             // Связующие фразы
    "intro": ["...", "..."],
    "aspect_intro": ["..."],
    "conclusion": ["..."],
    "solar_intro": ["..."]
  },
  "sphere_mapping": { ... },  // Маппинг сфер → домов
  "planet_weights": { ... }   // Веса планет для скоринга
}
```

### 5.2 Короткое описание (150-300 слов)

Генерируется функцией `generate_short_description()`:
1. Вступительная связующая фраза (случайная из `connectors.intro`)
2. **Солнце** в знаке + доме (2-3 предложения)
3. **Луна** в знаке + доме (2-3 предложения)
4. **Асцендент** в знаке (1-2 предложения)
5. **Ключевые аспекты** (топ-3): название + краткое описание типа аспекта
6. Заключительная фраза (из `connectors.conclusion`)

### 5.3 Полное описание

Генерируется функцией `generate_full_description()`:
1. Вступительная фраза
2. Для каждой из 10 планет:
   - Заголовок: символ + имя в знаке, номер дома, ретро
   - Планета в знаке (из `planets_in_signs`)
   - Планета в доме (из `planet_in_house`, full-версия)
   - Аспекты планеты (до 3 штук с орбами)
3. ASC и MC с градусами
4. Заключительная фраза

### 5.4 Скачивание PDF

Генерируется через `pdf_generator.py` (ReportLab):
- Шрифт с кириллицей (Arial или DejaVu Sans)
- Заголовок, данные рождения, таблица планет, таблица домов, толкования, дисклеймер
- Endpoint: `POST /api/generate-pdf`

| dashboard | `node src/server.js` | 3000 |

### 8.3 Процесс обновления

1. **Локально:** коммит → пуш → `git tag v1.1.0` → `git push origin v1.1.0`
2. **GitHub Actions:** собирает архив `solar-v1.1.0.tar.gz`, создаёт релиз
3. **Mac mini:** `~/solar/scripts/update.sh` → скачивает релиз → устанавливает зависимости → переключает симлинк → перезапускает PM2

### 8.4 Webhook (продакшн)

Для продакшн-режима MAX-бота нужен HTTPS. Варианты:
- **Cloudflare Tunnel** (рекомендуется)
- **ngrok** (для тестирования)

В `.env`: `WEBHOOK_URL=https://bot.your-domain.com/webhook`

## 10. Известные ограничения и TODO

### Текущие ограничения
1. **Состояния в памяти** — теряются при рестарте бота
2. **Один часовой пояс на город** — не учитывает исторические изменения
3. **Нет LLM** — описания из шаблонов, не персонализированные
4. **Нет кэширования** — одинаковые расчёты выполняются заново
5. **Pillow-рендер** — простой, без стилизации и водяных знаков
